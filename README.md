# Portfolio (Astro)

## Cómo correrlo

```bash
npm install
npm run dev
```

Abrí http://localhost:4321

## Cómo deployarlo (gratis)

1. Subí esta carpeta a un repo de GitHub.
2. Entrá a vercel.com, "New Project", importá el repo.
3. Vercel detecta Astro automáticamente. Deploy.

## Qué personalizar

- `src/pages/index.astro`: tu nombre, links, y el array `proyectos` con tus propios proyectos.
- `src/styles/global.css`: paleta de colores (variables al inicio del archivo) y tipografías.
